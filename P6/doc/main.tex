\section{Introducción y objetivos}
Los \textbf{objetivos} concretos de esta práctica son: 
\begin{itemize}
    \item Conocer cómo funcionan las técnicas de reconocimiento de imágenes. 
    \item Hacer un programa sencillo para realizar detección facial. 
\end{itemize}

\textbf{Repositorio} en GitHub: \url{https://github.com/ruiz314/PDIH/tree/main/P6}.\\ 

%----------------------------------------------------------------
%\newpage
%% Sección II
\section{Cuestiones a resolver}
Para superar esta práctica se proponen los siguientes ejercicios: 
\begin{enumerate}
    \item Hacer reconocimiento de caras de personas en imágenes (ejemplo básico).
    \item Hacer reconocimiento de caras de personas en vídeos.
    \item Hacer reconocimiento de caras de gatos en vídeos.
    \item Hacer simultáneamente el reconocimiento de cuerpos y caras de personas en vídeos. Es requisito que ambas cosas se detenten al mismo tiempo. Como sugerencia, se puede hacer una primera aproximación para hacer la detección en imágenes y posteriormente en vídeos. Para este ejercicio se facilita un vídeo de ejemplo, aunque se pueden usar otros diferentes. 
\end{enumerate}
