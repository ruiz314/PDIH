# Práctica 6. Reconocimiento de imágenes
## Objetivos de la práctica 
Los objetivos concretos de esta práctica son: 
- Conocer cómo funcionan las técnicas de reconocimiento de imágenes.
- Hacer un programa sencillo para realizar detección facial. 

[Memoria de la práctica](https://github.com/ruiz314/PDIH/blob/main/P6/memoriaP6.pdf)

## Cuestiones a resolver
1. Hacer reconocimiento de caras de personas en imágenes (ejemplo básico).

[ejercicio1.py](https://github.com/ruiz314/PDIH/blob/main/P6/ejer1/ejercicio1.py)

2. Hacer reconocimiento de caras de personas en vídeos.

[ejercicio2.py](https://github.com/ruiz314/PDIH/blob/main/P6/ejer2/ejercicio2.py)

3. Hacer reconocimiento de caras de gatos en vídeos.

[ejercicio3.py](https://github.com/ruiz314/PDIH/blob/main/P6/ejer3/ejercicio3.py)

4. Hacer simultáneamente el reconocimiento de cuerpos y caras de personas en vídeos. Es requisito que ambas cosas se detenten al mismo tiempo. Como sugerencia, se puede hacer una primera aproximación para hacer la detección 
en imágenes y posteriormente en vídeos. Para este ejercicio se facilita un vídeo de ejemplo, aunque se pueden usar otros diferentes.
