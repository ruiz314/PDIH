\section{Introducción y objetivos}
Los objetivos concretos de esta práctica son: 
\begin{itemize}
    \item Identificar y representar gráficamente la forma de onda de señales de sonido.
    \item Conocer la estructura de un fichero típico de sonido (ficheros WAV). 
    \item Entender y operar con los parámetros principales de una señal de sonido.
\end{itemize}


En el anexo\myref{anexo:an} se incluyen los ficheros de códigos al completo. \\

Para obtener los ficheros WAV he usado la página \url{https://speechgen.io/}.\\

Repositorio en GitHub: \url{https://github.com/ruiz314/PDIH/tree/main/P5}.\\

Para poder trabajar con R y RStudio en mi ordenador personal realicé los seminarios y tutoriales proporcionados por el profesor. Se encuentran en el siguiente repositorio: \url{https://github.com/ruiz314/PDIH/tree/main/S-sonido}.

\section{Requisitos mínimos}
 Para superar esta práctica se proponen los siguientes ejercicios, que se podrán realizar en un mismo programa:

\begin{itemize}
    \item Crear dos ficheros de sonido (WAV) para realizar los siguientes ejercicios. En el primero debe escucharse el nombre de la persona que realiza la práctica. En el segundo debe escucharse el apellido.
    \item Leer los dos ficheros de sonido creados y dibujar la forma de onda de ambos sonidos (por separado).

    \item Obtener la información de las cabeceras de ambos sonidos.

    \item Unir ambos sonidos en uno nuevo para escuchar el nombre y apellido correctamente.

    \item Dibujar la forma de onda de la señal y reproducir el sonido resultante (una vez unidos).

    \item Almacenar el sonido resultante en un archivo nuevo llamado ``basico.wav''  
\end{itemize}

\section{Requisitos ampliados}
Como requisitos ampliados (opcionales para subir nota) se propone:
\begin{itemize}
    \item Pasarle un filtro de frecuencia para eliminar las frecuencias entre 10.000Hz y 20.000Hz. Almacenar la señal obtenida como un fichero WAV denominado ``filtrado.wav''  
    \item Tomar el sonido que se creó antes (lo tendremos en el archivo llamado ``basico.wav'') para aplicarle el efecto de eco. Guardar ese sonido en un archivo nuevo llamado ``eco.wav''. A continuación, se le debe dar la vuelta al sonido y almacenarlo como un fichero llamado ``alreves.wav''
\end{itemize}
