\section{Introducción}
El objetivo principal es conocer cómo utilizar el lenguaje Postscript a nivel básico. \\

Los objetivos concretos de esta práctica son: 
\begin{itemize}
    \item Conocer la sintaxis básica del lenguaje Postscript.
    \item Crear varios archivos y probar el funcionamiento con un visor Postscript. 
    \item Transformar los ejemplos creados a otros formatos de archivo, como PDF. 
\end{itemize}
